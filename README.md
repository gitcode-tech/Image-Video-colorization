# Log Analyzer

A lightweight cybersecurity log analysis tool built with Python, SQLite, and Flask.

The project analyzes authentication logs, identifies repeated failed login attempts, and generates security alerts that can be viewed through a simple web dashboard.

## Features

* Parse Linux-style SSH authentication logs
* Detect repeated failed login attempts
* Identify IP addresses associated with suspicious login activity
* Generate brute-force alerts
* Store alerts in SQLite
* View detected alerts through a Flask web interface

## Technologies

* Python 3
* Flask
* SQLite
* Regular Expressions
* HTML/CSS
